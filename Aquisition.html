Creating string functions

save_countries <- function(country) {
  write_csv(country, paste0("data/clean/", deparse(substitute(country)), ".csv"))
}

lengthen_countries <- function(csv) {
  csv %>% 
    pivot_longer(
      cols = !c("Country Name", "Country Code", "Indicator Name", "Indicator Code"),
      names_to = "Year",
      values_to = "Value"
    )
}

clean_countries <- function(country) {
  lengthen_countries(country) %>% 
    select(`Country Name`, `Indicator Name`, Year, Value) %>% 
    filter(`Indicator Name` %in% indicators)
}

We created string functions so that it is easier to clean the data and save to new folder since there is 9 countries we have to do this for.

This is what we used to turn the variable names into string functions inside dplyr. https://stackoverflow.com/questions/71487035/turn-variable-name-into-string-inside-function-dplyr
